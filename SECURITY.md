# Security Policy

## Reporting Security Issues

The Kubeflow maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kubeflow/kubeflow/security/advisories/new) form.

For more details, see the [Kubeflow security policy](https://github.com/kubeflow/kubeflow/blob/master/SECURITY.md).
